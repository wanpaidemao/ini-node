## 一、第一性原理

### 1.1 使命与约束

全节点钱包一体机：**尽快收敛到网络一致状态 + UI 始终可交互**。
不可妥协三约束：共识正确、崩溃一致性（状态/UTXO/索引/水印四线不互领先）、内存有界（44M 高度窗口化是被迫）。

### 1.2 两个公式（一切方案的可检验来源）

```
吞吐  R = min(R_net, R_val, R_write)   ← 改非瓶颈无益（header 不是瓶颈，块侧才是）
延迟  L = ① 链写锁等待 + ② blockHandler 排队 + ③ 代理传输   ← 三段各有一个方案组
优化 = L1 消除浪费 → L2 缩小临界区 → L3 卸载阻塞 → L4 并行化（层序执行，先便宜后贵）
```

### 1.3 全部优化项一览（按层归类）

| 层 | 后端 | 前端 |
|---|---|---|
| L1 消除浪费 | D4 清 14 处 TEMP-DBG、D1 删 suspiciousHeaders、D3 前端读实际 headerwindow | F1 轮询降频、F2 轮询合并、O7 代理超时、F8 time 事件降频、F9 打包瘦身 |
| L2 缩小临界区 | N1=A5-1 通知移出链写锁、A1 两阶段校验（轻量版）、A2 链锁分域 | — |
| L3 卸载阻塞 | O1 sync 快照免排队、O3 UTXO flush 后台化、A3 写盘队列、A5 事件总线、A7 日志异步 | F10 启动解耦 |
| L4 并行化 | A1 锁外校验、A4 UTXO 分层预取 | F6 余额批量 |
| 横切 | A6 metrics（O8 扩）、O8 冷读埋点、O2 请求窗口缓存、O6 lead 放宽、D2 headers 语义 | F3 写盘期降级 |
| 排除 | A8 索引服务化（不做） | — |

## 三、后端方案（按层）

### 3.1 L1 消除浪费

| 项 | 内容 | 证据 |
|---|---|---|
| D4 | 删 14 处 TEMP-DBG（锁内 2 处热路径） | `manager.go` NTBlockAccepted 每块必打；`sendNotification` 同步回调在链写锁内 |
| D1 | 删 `suspiciousHeaders`（只写不读） | manager.go:2940 写、全库无读 |
| D2 | `getblockchaininfo.headers` 填真实 tip | 现恒等于 blocks；读 O1 快照 |
| D3 | 前端读实际 headerwindow | Dashboard.svelte:97 硬编码 50000 |

### 3.2 L2 缩小临界区

| 项 | 内容 | 边界 |
|---|---|---|
| N1=A5-1 | `NTBlockAccepted` 解锁后通知（对齐 NTBlockConnected 模式） | mempool 保序单消费者 |
| A1-轻量 | 入队前完成反序列化/sanity/PoW（锚点区）+ UTXO 预取；连接只做提交 | 脚本校验依赖 tip 视图，基本无法完全锁外 |

### 3.3 L3 卸载阻塞

| 项 | 内容 |
|---|---|
| O1 | SyncStatus 无锁快照（`atomic.Pointer`），RPC 不排 msgChan → **G1 主修复** |
| O3 | UTXO flush 后台（先序列化再短持锁批量提交） |
| A3 | 写盘队列：块体与元数据解耦，元数据 N 块合并 + 高度水印重放 |
| A7 | 日志异步 writer，链锁内零日志 I/O |

### 3.4 L4 并行化

| 项 | 内容 |
|---|---|
| A1-全 | 校验节点池（UTXO 预取、无状态校验）→ 串行提交 |
| A4 | UTXO 热区/预取队列/冷区分层 + 分代 flush |

### 3.5 横切（参数与可观测）

| 项 | 内容 |
|---|---|
| O8=A6-子集 | 冷读命中/驱逐计数暴露到 `getblocksyncstatus` |
| A6 | 统一原子指标：blocks/s、锁等待、flush 耗时、队列深度、日志字节 |
| O2 | 请求窗口 hash 滑动缓存（回退重下段不冷读，解耦 lead 与 W） |
| O6 | lead 放宽至 ≤57000（余量 ≥1000）：只增韧性不提速 |

## 五、架构层面改造（A 系列，独立轨道）

### 5.1 现状 → 目标分层

```
现状：peer → msgChan → blockHandler(串行) 
      [校验+写盘+通知 全在链写锁内] + [UTXO 全量 flush 锁内] + [RPC 排队]
目标：输入(可并行) → 锁外校验(可并行) → 串行提交(短锁) → 写盘层(独立 writer+水印)
      └ 事件异步 └ 日志异步 └ metrics 横切
```

### 5.2 各项风险纵深（机制/失效/验证）

| 项 | 收益机制 | 最坏失效 | 验证 |
|---|---|---|---|
| A5 事件总线 | 通知不阻塞块连接 | mempool 乱序→滞留；漏通知 | 同步+挖矿回归 |
| A6 指标层 | 一切 A 的基线 | 无（纯增量） | — |
| A1 两阶段 | 临界区缩短 | UTXO 视图过期→重校验/丢弃，脚本难全锁外 | A6 前/后吞吐 + 竞争/回滚交叉 |
| A4 UTXO 分层 | 读放大↓、flush 消失 | 预取版本绑定错→旧视图 | 同步+回滚回归 |
| A3 写盘队列 | 写事务 ÷N | **四线一致错位→重启重建或丢状态**（同型 P8/P9） | kill -9 随机点 + 一致性断言 |
| A2 链锁分域 | 锁近零 | 跨域 race（回滚 4 域联动漏审） | race detector + 洪流压测 |
| A7 日志异步 | 锁内零日志 I/O | 崩溃丢尾（可接受） | — |
| A8 服务化 | （不做） | 收益有限、运维复杂 | — |

依赖链：**A6 先行 → A5 → A4 → A3 → A2**；A2 依赖 A1 边界、A4 依赖 A1 锁外预取，不得跳序。

## 七、路线图（层优先 + 轨道并行）

```
P0（L1 止血，独立）: D4 → D1 → F1 → F2/O7
P1（L2/L3，独立）: O1 → N1 → D2 → O3 → O2（先 O8 埋点）
轨道（独立评审/独立回退）: A6 → A5 剩余 → A4 → A3 → A2（依赖链内不跳序）
P2-P3（体验）: F3/F4-F10 → O6 → D3
```

### P0 验收
写盘期详情页无 5s 超时；日志量下降；`go build ./...` + `svelte-check` 0 err。

### P1 验收
flush 期 `getblockchaininfo`/`getblocksyncstatus` < 1s；重启无 UTXO 重建；回退重下段速度 = 正常段。

### 轨道验收
每刀：A6 基线前后（吞吐/锁等待/flush 耗时）+ 人工构造分叉/孤儿洪流/竞争失败的自愈回归；kill -9 随机点重启一致性。

---

## 八、验收指标（总）

1. 写盘期 `getblocksyncstatus` < 1s，前端无超时（G1）。
2. IBD 无 >10s 零速段；回退重下段不冷读（G2）。
3. 删库全量重同步 ≤ 8h（G3）。
4. 日志 ≤ 数百 MB；写事务数下降 ≥50% 有数据（G4）。
5. RSS 有界（G5）。
6. 全部优化有 A6 基线佐证，无"凭感觉变快"。
