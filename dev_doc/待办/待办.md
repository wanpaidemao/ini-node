### 4. 独立 P2P 测试工具 p2ptest（2026-08-29）🔨 骨架完成

**目标**：把 `backend/devtest/` 下零散的 P2P 探测小程序汇聚成一个独立的统一测试工具，
后续逐步加入更多子命令（getaddr / ping / headers / version-check / rpc 等）。

**设计约束**：
1. **独立 Go module**：`backend/cmd/p2ptest/` 自带 `go.mod`（嵌套 module），
   `go build ./...`（backend）自动排除它，**不影响主项目编译**（已验证）。
2. **脱离项目运行**：单独编译出独立二进制，命令行为主，后续可再包 GUI。
3. **复用 wire 包**：通过 `replace github.com/btcsuite/btcd/wire/v2 => ../../wire` 复用，
   只读其导出 API。
4. **依赖放 D 盘**：构建时用 `GOMODCACHE=D:\codeX\gomodcache`（不落 C 盘）。
5. 编码 UTF-8，注释中英双语。

**结构**：
```
backend/cmd/p2ptest/
├── go.mod      # 独立 module，replace 到 ../../wire
├── main.go     # 子命令路由 + 帮助
├── probe.go    # 骨架：读对端 version（未来替代 devtest/nover）
├── shake.go    # 骨架：完整握手（未来替代 devtest/main）
└── raw.go      # 骨架：静默裸读（未来替代 devtest/rst）
```

**构建/运行**：
```bash
cd backend/cmd/p2ptest
$env:GOMODCACHE='D:\codeX\gomodcache'   # 依赖不落 C 盘
go build -o p2ptest.exe .
.\p2ptest.exe help                        # 查看子命令
.\p2ptest.exe probe 127.0.0.1:34230       # 骨架占位
```

**下一步（待做）**：
1. 实现 `probe`：连接目标 P2P 端口，读对端第一个 version 消息并打印 agent/subver/pver/lastBlock
2. 实现 `shake`：发送 version+verack，读对端回复（迁移 devtest/main）
3. 实现 `raw`：静默连接读原始字节（迁移 devtest/rst）
4. 新增子命令：`getaddr` / `ping` / `version-check`（校验节点上报 subver 是否符合预期）/ `rpc`

**相关文件**：
- `backend/cmd/p2ptest/*.go`（工具本体）
- `backend/devtest/*`（待迁移的旧工具）
- `backend/wire/msgversion.go`（AddUserAgent / ReadMessage 等复用点）
